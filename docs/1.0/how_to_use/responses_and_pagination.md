# Unified Responses & Pagination

AsasFlow provides a standardized JSON response contract across all generated module controllers, custom routes, middleware, cached endpoints, and framework exceptions.

---

## Standard JSON Envelope

### 1. Paginated `GET` Response

```json
{
  "success": true,
  "message": "Success",
  "data": [
    {
      "id": 1,
      "name": "Alice",
      "email": "alice@example.com"
    },
    {
      "id": 2,
      "name": "Bob",
      "email": "bob@example.com"
    }
  ],
  "meta": {
    "current_page": 1,
    "per_page": 15,
    "total": 42,
    "last_page": 3,
    "from": 1,
    "to": 15,
    "has_more_pages": true
  }
}
```

### 2. Single Resource / Action Success Response

```json
{
  "success": true,
  "message": "Success",
  "data": {
    "id": 1,
    "name": "Alice",
    "email": "alice@example.com"
  }
}
```

### 3. Error & Validation Response (`400`, `401`, `403`, `404`, `422`, `500`, `501`)

```json
{
  "success": false,
  "message": "Validation failed",
  "errors": {
    "email": [
      "The email field is required."
    ]
  }
}
```

## Architecture Overview

| Component | Namespace | Responsibility |
|-----------|-----------|----------------|
| `ApiResponseFactory` | `Bitsnio\AsasFlow\Foundation\Http\ApiResponseFactory` | Constructs `success`, `created`, `paginated`, and `error` responses, unwrapping Laravel `JsonResource` and `ResourceCollection` instances without creating nested `data.data`. |
| `PaginationResolver` | `Bitsnio\AsasFlow\Foundation\Http\Pagination\PaginationResolver` | Resolves `page` and `per_page` query parameters, enforces safe limits, handles opt-in unpaginated requests, and normalizes pagination `meta`. |
| `JsonResponseTrait` | `Bitsnio\AsasFlow\Foundation\Http\Traits\JsonResponseTrait` | Thin controller trait automatically included on generated controllers. |
| `ApiExceptionRenderer` | `Bitsnio\AsasFlow\Foundation\Http\Exceptions\ApiExceptionRenderer` | Normalizes uncaught validation (`422`), authentication (`401`), authorization (`403`), not-found (`404`), and server (`500`) exceptions into the standard error envelope. |

## Controller Usage (`JsonResponseTrait`)

All controllers generated by `php artisan asasflow:generate-controllers` or `php artisan asasflow:generate-from-schema` automatically use `JsonResponseTrait`.

```php
<?php

namespace Modules\Core\Http\Controllers;

use Bitsnio\AsasFlow\Foundation\Http\Traits\JsonResponseTrait;
use Illuminate\Http\JsonResponse;
use Illuminate\Http\Request;
use Illuminate\Routing\Controller;
use Modules\Core\Http\Requests\UserRequest;
use Modules\Core\Http\Resources\UserResource;
use Modules\Core\Models\User;

class UserController extends Controller
{
    use JsonResponseTrait;

    public function index(): JsonResponse
    {
        $items = $this->paginateQuery(User::query(), 15);

        return $this->paginatedResponse(
            UserResource::collection($items)
        );
    }

    public function store(UserRequest $request): JsonResponse
    {
        $item = User::create($request->validated());

        return $this->createdResponse(
            new UserResource($item)
        );
    }

    public function show(User $user): JsonResponse
    {
        return $this->successResponse(
            new UserResource($user)
        );
    }

    public function update(UserRequest $request, User $user): JsonResponse
    {
        $user->update($request->validated());

        return $this->successResponse(
            new UserResource($user)
        );
    }

    public function destroy(User $user): JsonResponse
    {
        $user->delete();

        return $this->successResponse(
            null,
            'Deleted successfully'
        );
    }
}
```

### Available Trait Methods

| Method | HTTP Status | Description |
|--------|-------------|-------------|
| `$this->paginateQuery($query, ?int $defaultPerPage = null, bool $allowUnpaginated = false)` | — | Paginates an Eloquent/Query builder or relation using `?page=` and `?per_page=`. |
| `$this->paginatedResponse($items, string $message = 'Success', int $status = 200, array $headers = [], array $meta = [])` | `200` | Formats a `LengthAwarePaginator`, `Paginator`, `ResourceCollection`, `Collection`, or `array` with `data` + `meta`. |
| `$this->successResponse($data = null, string $message = 'Success', int $status = 200, array $headers = [], array $meta = [])` | `200` | Formats a single resource or payload. |
| `$this->createdResponse($data = null, string $message = 'Created successfully', array $headers = [], array $meta = [])` | `201` | Formats a newly created resource response. |
| `$this->cachedResponse(callable $callback, ?int $ttl = null, array $tags = [])` | `200` / `304` | Caches a `GET` response through AsasFlow's `CacheManager`. |
| `$this->errorResponse(string $message = 'Error', int $status = 400, mixed $errors = null, array $headers = [])` | `400–599` | Formats an error response (validates that `$status` is between `400` and `599`). |
| `$this->notFoundResponse(string $message = 'Resource not found.')` | `404` | Convenience `404` error helper. |
| `$this->validationErrorResponse(mixed $errors, string $message = 'Validation failed')` | `422` | Convenience `422` validation error helper. |
| `$this->unauthorizedResponse(string $message = 'Unauthenticated.')` | `401` | Convenience `401` unauthenticated helper. |
| `$this->forbiddenResponse(string $message = 'Forbidden.')` | `403` | Convenience `403` forbidden helper. |
| `$this->notImplementedResponse(string $message = 'Not implemented')` | `501` | Convenience `501` helper used for unimplemented stubs. |

## Pagination Rules & Configuration

Pagination behavior is configured in `config/asasflow.php` under `generators.controller.features.pagination`:

```php
'pagination' => [
    'enabled' => true,
    'per_page' => 15,
    'max_per_page' => 100,
    'allow_unpaginated' => false,
    'max_unpaginated' => 500,
],
```

### Query Parameter Behavior

- **`?per_page=25`**: Sets items per page, clamped between `1` and `max_per_page` (`100`).
- **Invalid `per_page`** (`0`, `-5`, `abc`, `all`): Safely normalizes to the default `per_page` (`15`). Unlimited `?per_page=all` retrieval is rejected to protect memory and response times.
- **`?page=2`**: Navigates to page 2. Invalid or negative values (`0`, `-1`, `abc`) normalize to page `1`.
- **Opt-in `?paginate=false`**: Disabled by default (`allow_unpaginated => false`). To allow unpaginated retrieval on a specific dropdown/lookup endpoint, pass `allowUnpaginated: true` to `paginateQuery()`:

```php
public function index(Request $request): JsonResponse
{
    $items = $this->paginateQuery(
        Country::query()->orderBy('name'),
        defaultPerPage: 25,
        allowUnpaginated: true, // Honors ?paginate=false up to max_unpaginated (500)
    );

    return $this->paginatedResponse(
        CountryResource::collection($items)
    );
}
```

## Preserving Custom Resource Metadata

When returning a `JsonResource` or `ResourceCollection` that defines `with(Request $request)` or `->additional([...])`, `ApiResponseFactory` automatically unwraps the resource items into `data` (preventing nested `data.data`) and merges your custom metadata into `meta`:

```php
class UserResource extends JsonResource
{
    public function toArray(Request $request): array
    {
        return [
            'id' => $this->id,
            'name' => $this->name,
        ];
    }

    public function with(Request $request): array
    {
        return [
            'meta' => [
                'exportable' => true,
            ],
        ];
    }
}
```

## Response Macros for Custom Routes & Middleware

In `routes/custom.php` closures or middleware where `$this` is not a controller, use Laravel's `response()` macros backed by `ApiResponseFactory`:

```php
use Illuminate\Support\Facades\Route;
use Modules\Core\Http\Resources\UserResource;
use Modules\Core\Models\User;

Route::get('users/featured', function () {
    $paginator = User::where('featured', true)->paginate(10);

    return response()->paginated(
        UserResource::collection($paginator),
        'Featured users retrieved'
    );
});

Route::post('users/{user}/activate', function (User $user) {
    if ($user->is_banned) {
        return response()->error('Banned users cannot be activated.', 403);
    }

    $user->update(['active' => true]);

    return response()->success(new UserResource($user), 'User activated');
});
```

## Integration with AsasFlow Cache (`src/Features/Cache`)

Unified responses integrate directly with AsasFlow's HTTP cache system:

1. **Auto-Detected Model Tags**: When `ApiResponseFactory` builds a `success` or `paginated` response from Eloquent models (directly or inside a `JsonResource` / `ResourceCollection` / `LengthAwarePaginator`), it automatically extracts model cache tags (`model:Modules_Core_Models_User`, `model:Modules_Core_Models_User:1`, plus any `$cacheTags` defined via `CacheAware`).
2. **Deterministic Pagination Cache Keys**: `CacheKeyGenerator` sorts query parameters (`?page=1&per_page=15` matches `?per_page=15&page=1`) and ignores marketing parameters (`utm_source`, `_ga`, etc.).
3. **`ETag` & `304 Not Modified`**: Cached `JsonResponse` payloads include `ETag` and `X-AsasFlow-Cache: HIT|MISS` headers and automatically return `304 Not Modified` when `If-None-Match` matches.
4. **Error Exclusion**: Responses with `success: false` or HTTP status `>= 400` are never cached.
